# Privacy Policy

_Last updated: November 4, 2026_

Equilotl is an open-source installer for Equicord. This policy explains what the software does with your data.

## Data we collect

Equilotl does not collect, store, or transmit any personal information to the maintainers. It has no analytics, telemetry, tracking, or user accounts.

## Network requests

To work, Equilotl makes network requests to GitHub (github.com and api.github.com) to download Equicord files and to check for new versions of the installer. These requests are handled by GitHub and are subject to the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement). The maintainers do not receive or log these requests.

## Local changes

Equilotl reads and modifies files of a Discord installation on your own computer in order to install or uninstall Equicord. All of this happens locally. Your files and Discord data are not uploaded anywhere.

## Third parties

Equilotl does not share data with any third party and does not include advertising.

## Changes to this policy

Any changes will be published in this file in the repository.

## Contact

Questions can be raised by opening an issue at https://github.com/haveancieday/Equilotl/issues.
